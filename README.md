# ルーンテイマー迷宮記 (RuneTamer Labyrinth)

Cloudflare Pages の完全静的ホスティングだけで完結する、**16bit王道ファンタジー・ドット絵モンスター収集＆装備ハクスラやり込みRPG** です（スマホ縦画面・片手操作最優先）。

## 主な特徴

- **完全コード生成 16bit ドット絵**：主人公＋仲間モンスター20種＋4バイオーム＆始まりの村＋装備アイコンをすべて高精細ピクセルアートで描画（外部画像アセット不要・超軽量）。
- **主人公＋仲間モンスター最大3体（4人パーティ）**：撃破で仲間化＆既所持は `★覚醒` で永続強化。4人全員が **武器 / 防具 / 遺物 / ルーン** の4枠（計16枠）を装備可能。
- **ハクスラ装備厳選**：6段階レアリティ（Common〜Mythic）＋ランダムOP＋ビルドを変える固有ユニーク装備14種。片手1タップ比較・ロック・一括売却・自動売却フィルタ完備。
- **自動生成2Dダンジョン＆ターン制コマンド戦闘**：タップ移動／十字キー／オート探索に対応。戦闘は手動コマンドとオート作戦AI・倍速（1x/2x/4x）を自在に切替可能。
- **リセット無し「世界ランク（転生Tier）」**：20Fボス撃破で上位Tier解放。キャラ・装備を失わず、恒久加護と上位ドロップ上限を無限に伸ばせます。
- **完全ローカルセーブ**：`localStorage` 自動保存＋チェックサム付きセーブコード（`RTL1:...`）の出力・復元対応。

## 開発・テストコマンド

```bash
npm install
npm run dev      # ローカル開発サーバー
npm test         # ユニットテスト実行 (Vitest)
npm run build    # TypeScript型チェック + 本番静的ビルド (dist/)
```

## Cloudflare Pages デプロイ設定

1. このディレクトリを GitHub リポジトリにプッシュ（または `npx wrangler pages deploy dist` で直接デプロイ）。
2. Cloudflare Pages のプロジェクト設定で以下を指定：
   - **Framework preset**: `Vite`
   - **Build command**: `npm run build`
   - **Build output directory**: `dist`
3. `public/_redirects` および `public/_headers` が同梱されているため、追加設定不要でそのまま公開できます。
