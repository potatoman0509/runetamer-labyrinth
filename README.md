# ルーンテイマー迷宮記 (RuneTamer Labyrinth)

Cloudflare Pages の完全静的ホスティングだけで完結する、**16bit王道ファンタジー・ドット絵モンスター収集＆装備ハクスラやり込みRPG** です（スマホ縦画面・片手コマンド選択進行・PWA対応）。

## 主な特徴

- **フィールド移動なしのサクサク・コマンド進行**：毎回表示される3択ルート（通常戦／強敵／宝箱・黄金箱／呪いの祭壇／怪しい宝箱＆ミミック／希少遭遇「黄金スライム・虚無の使徒」／迷宮の行商人／旅の鍛冶師／祝福の祠／階層ボス）を親指1タップで選んで進行！`▶オート進行` ONでおまかせ周回も自在。
- **完全コード生成 16bit ドット絵サイドビュー**：始まりの村＆4バイオーム（緑の森／古代遺跡／溶岩洞窟／星屑の深淵）を行進する4人パーティ＋敵味方アニメーション戦闘＋装備アイコンをすべて高精細ピクセルアートで描画（外部画像アセット不要）。
- **主人公＋仲間モンスター最大3体（4人パーティ）**：希少魔物（宝箱ミミック・黄金スライム・虚無の使徒）を含む**全23種**を撃破で仲間化＆既所持は `★覚醒` で永続強化。さらに同属性・ロール揃えで**パーティ編成シナジー**が発動！
- **奥深いハクスラ装備＆鍛冶システム**：
  - 4人全員が **武器 / 防具 / 遺物 / ルーン** の4枠（計16枠）を装備可能。
  - 6段階レアリティ（Common〜Mythic）＋**6系統セット装備（2部位/4部位効果）**＋**固有ユニーク装備26種**。
  - **失敗なし＋15確定強化（＋5/＋10/＋15で全OP+25%底上げのブレイクスルー！）**、**OP 1枠指定リロール（再鍛造）**、**自動売却／自動分解（鍛冶石）切替**＆一括処理完備。
- **リセット無し「世界ランク（転生Tier）」**：20Fボス撃破で上位Tier解放。キャラ・装備を失わず、恒久加護と上位ドロップ上限を無限に伸ばせます。
- **完全ローカルセーブ＆PWA対応**：`localStorage` 自動保存＋チェックサム付きセーブコード（`RTL1:...`）出力/復元対応。スマホの「ホーム画面に追加」でアプリ風に遊べます。

## 開発・テストコマンド

```bash
npm install
npm run dev      # ローカル開発サーバー
npm test         # ユニットテスト実行 (Vitest)
npm run build    # TypeScript型チェック + 本番静的ビルド (dist/)
npm run lint     # Oxlint チェック
```

## Cloudflare Pages デプロイ手順

1. Cloudflare ダッシュボード → **Workers & Pages** → **Create** → **Pages** → **Connect to Git** を選択。
2. GitHub リポジトリ `runetamer-labyrinth` を選択し、ビルド設定を以下にする：
   - **Framework preset**: `Vite`
   - **Build command**: `npm run build`
   - **Build output directory**: `dist`
3. 「Save and Deploy」を押せば数分で公開完了！（`public/_redirects`, `public/_headers`, `public/manifest.webmanifest`, `public/sw.js` 同梱済み）
